# User Guide

This section helps operators set up, configure, and run EagleEye. Placeholders mark spots where environment-specific details need to be filled in later.

## What you can do
- Prepare the host and compute devices.
- Configure pipelines and cameras.
- Run the system locally and access the WebUI.
- Troubleshoot common issues.

## Prerequisites
- Python environment with project dependencies installed.
- Access to required models, camera calibration files, and AprilTag maps.
- At least one supported compute device (CPU/GPU/MX3).
