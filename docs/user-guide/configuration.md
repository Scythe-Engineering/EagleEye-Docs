# Configuration

EagleEye has two configuration files: `pipeline_config.json` (the pipeline DAG) and `general_conf.json` (NetworkTables address). Both are edited via the WebUI or directly as JSON.

## Pipeline config — `src/config/pipeline_config.json`

Each top-level key is a **pipeline name**. A pipeline maps to one or more cameras and contains an ordered list of operation nodes connected as a directed acyclic graph (DAG).

### Full schema

```json
{
  "PipelineName": [
    {
      "action_name": "device_input.py",
      "action_params": {
        "bus_id": "1-3.2",
        "frame_rotation": 0
      },
      "position": { "x": 100, "y": 100 },
      "uuid": "op-mljk5q36-arwb",
      "connections": [
        {
          "from_uuid": "op-mljk5q36-arwb",
          "from_port": "frame",
          "to_uuid": "op-mljk60f4-az78",
          "to_port": "frame",
          "data_type": "frame",
          "is_default": false,
          "custom_waypoints": null
        }
      ]
    }
  ]
}
```

### Field reference

| Field | Type | Description |
|---|---|---|
| `action_name` | string | File name of the operation (e.g. `detect_apriltags.py`) |
| `action_params` | object | Constructor kwargs forwarded to the operation. Injected params are added automatically (see below). |
| `position` | `{x, y}` | Canvas position in the pipeline editor. Cosmetic only. |
| `uuid` | string | Stable unique ID for this node. Generated by the editor; format `op-<random>`. |
| `connections` | array | Edges FROM this node to downstream nodes. |
| `connections[].is_default` | bool | If `true`, this is a temporal edge — the receiving operation gets the **previous frame's** output from this connection rather than the current frame. Used for feedback loops. |

### Injected parameters

These are passed automatically to any operation constructor that declares them — you do not include them in `action_params`:

| Parameter | Type | What it provides |
|---|---|---|
| `web_interface` | `EagleEyeInterface` | Access to the Flask server for SSE, visualization, config hooks |
| `compute_pool` | `ComputePool` | Device lookup by ID |
| `network_table` | `NetworkTable` | Direct NT table handle |
| `camera_manager` | `CameraThreadManager` | Access to live camera frames by bus ID |
| `camera_config_registry` | `CameraConfigRegistry` | Intrinsics and extrinsics per camera |
| `logger` | `Logger` | Shared logger |

### The `{project_root}` token

Any string value in `action_params` that contains `{project_root}` is resolved to the absolute project directory at runtime:

```json
"apriltag_map_path": "{project_root}/files/apriltag_map_path/frc2025r2.json"
```

### Device IDs

Device IDs must match what `ComputePool` registers at startup:

| Device | ID format | Example |
|---|---|---|
| CPU | `CPU` | `CPU` |
| NVIDIA GPU | `GPU_<index>` | `GPU_0` |
| Memryx MX3 | `MX3_<index>` | `MX3_0` |

## General config — `src/general_conf.json`

Controls the NetworkTables server address. Created automatically on first run.

```json
{
  "network_table_address": "10.TE.AM.2"
}
```

Set to `0.0.0.0` to disable NT publishing (useful when testing without a robot).

This file is editable via the **Settings** tab in the WebUI. Changes take effect after restarting the backend.
